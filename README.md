# SocialSpyAgent Web

Web/Vercel edition of SocialSpyAgent for public social-media OSINT.

- Web UI: `/`
- Health: `/api/health`
- Search API: `POST /api/search`

Environment variables:

- `GOOGLE_API_KEY` for YouTube
- `RAPIDAPI_KEY` for Instagram/TikTok

The original terminal interface is also included for local use.
